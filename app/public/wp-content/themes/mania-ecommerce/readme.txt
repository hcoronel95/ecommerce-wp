== Description ==

Mania eCommerce Theme is a modern, customizable WooCommerce theme for building fast, professional online stores. It offers responsive layouts, powerful customization options, Elementor compatibility, and WooCommerce features like wishlist, quick view, AJAX search, product filtering, promotional banners, and featured collections. Ideal for fashion, electronics, furniture, grocery, beauty, jewelry, and more, Mania is SEO-friendly, translation-ready, RTL-compatible, and designed to help create engaging stores that drive sales.
